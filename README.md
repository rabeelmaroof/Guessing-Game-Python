# 🤖 AI Number Guessing Game - Python

A simple and intelligent number guessing game built with Python. This is my first project towards my journey of BS Artificial Intelligence.

### 🎯 How it Works
- AI selects a secret number between 1 to 100
- Player gets 7 chances to guess
- AI gives smart hints: Too High / Too Low
- Game shows result with total attempts

### 🛠️ Technologies
- Python 3
- Random Module
- While Loop, If-Else Logic
- Input Validation & Error Handling
